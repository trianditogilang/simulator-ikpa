# System Debugging Skill

Fokus pada pendekatan investigatif yang terstruktur untuk menemukan dan memperbaiki bug pada sistem dan codebase.

## Workflow Debugging
1. **Reproduce & Isolate**:
   - Pahami kondisi pasti pemicu bug dan isolasi dependensi atau alur input terkait.
2. **Root Cause Analysis (Bukan Quick Patch)**:
   - Analisis stack trace, log, network requests, dan lifecycle/state changes untuk menemukan akar penyebab sebenarnya.
3. **Hypothesis & Verification**:
   - Buat hipotesis terarah, uji asumsi dengan logging / unit test / breakpoint.
4. **Fix & Regression Prevention**:
   - Terapkan perbaikan yang bersih dan pastikan tidak menimbulkan side-effects pada modul lain.
