# Emil Design Engineering Skill

Fokus pada jembatan antara desain tingkat tinggi dan implementasi rekayasa frontend (*Design Engineering*).

## Prinsip & Best Practices
- **Design System Architecture**: Membangun komponen yang reusable, typesafe, dan konsisten (variant-based, composable).
- **Fluid & Gesture Animations**: Memanfaatkan physics-based animation (Framer Motion / Tailwind animations / CSS spring transitions).
- **Accessibility & UX Details**: Keyboard navigation, ARIA attributes, semantic HTML, dan feedback latency rendah.
- **State-driven UI**: Mengelola visual feedback yang tepat pada loading, error, empty, dan edge case states.
